# Security and Responsible Disclosure

This repository contains sanitized notes associated with previously reported TRON peer-handling research.

Live infrastructure addresses, operational denial-of-service commands, automated impact workflows, and unverified severity claims have been removed from the default branch.

Do not test public TRON infrastructure. Reproduction must be limited to an isolated local testnet or synthetic peers under explicit authorization.

Report potential TRON vulnerabilities through the official HackerOne program or the security contact published by the project.
